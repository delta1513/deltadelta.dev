## What I used for this website 🌐

- [Tailwind](https://tailwindcss.com/) - You probably already know it but worth a mention. It makes my life so much easier!
- [11ty/eleventy](https://www.11ty.dev/) - They had me with the opossum! I use this to generate my blog pages
- [Obsidian](https://obsidian.md/) - A really neat text editor that I use for taking notes personally and for work

## Getting around things 🕵️‍♂️

- [Iroh Dumbpipe](https://github.com/n0-computer/dumbpipe) - Software you can use to transfer data or make connections any two computers in the world. Uses NAT hole-punching in a cool way.
- [yt-dl](https://github.com/yt-dlp/yt-dlp) - Download youtube videos locally (also has various front-ends out there)

## Self-hosting 🖥️

- [Awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted) - awesome list of awesome stuff you can self-host.
- [The discord music bot software I use](https://github.com/Just-Some-Bots/MusicBot) - This one does all the stuff that my friends love (like round-robin playlists/queues) and also support spotify and anything that [yt-dl](https://github.com/yt-dlp/yt-dlp) supports.
- [microsocks](https://github.com/rofl0r/microsocks) - great if you need a HTTP proxy really quickly
- [Syncthing](https://syncthing.net/) - E2E encrypted folder synchronisation (Basically your own dropbox)

## Link fixers

These are services that help embed things properly into chat apps like Discord

### Twitter

"twitter.com" -> "[vxtwitter.com](https://vxtwitter.com/)"

"x.com" -> "[fixupx.com](https://fixupx.com/)"

### Instagram

"instagram.com" -> "[ddinstagram.com](https://ddinstagram.com/)"

### Tik-tok
